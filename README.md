# Karsten Berry — Frontend Developer Portfolio

A lightweight, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and project details
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation and automatic footer year

## Projects featured

- [BBC Website](https://github.com/KBindustries/BBC-website)
- [Mortgage Calculator](https://github.com/KBindustries/mortgage)
- [System Dashboard](https://github.com/KBindustries/System)

The System Dashboard card notes that it is based on the Windmill Dashboard React starter. Update project descriptions as your own work evolves, and add live demos only when they are available.

## Run locally

Download or clone this repository, then open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the deployment to finish. GitHub will display the live website URL in the Pages section.

The expected URL for this repository is usually:

`https://kbindustries.github.io/Portfolio/`

If the link does not work yet, check the URL shown in **Settings → Pages**.

## Before sharing with clients

- Verify every project link and description.
- Add a professional email or WhatsApp contact link if you want clients to reach you directly.
- Add live project demos when they are ready.
- Keep the project descriptions honest about what you built and what came from a starter template.
